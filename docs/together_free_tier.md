# Together AI Free Tier — Research Summary

**Last verified**: August 2026, via together.ai/pricing.

## What is Together AI?

Together AI provides serverless inference, dedicated endpoints, fine-tuning, and GPU clusters for open-source models.

**Base URL**: `https://api.together.xyz/v1`

## Free Tier Limits

| Limit | Value | Notes |
|-------|-------|-------|
| Free credits | None explicit | Pay-as-you-go only |

Together AI does not appear to have a standing free tier. New accounts may receive promotional credits.

## Available Models

Extensive catalog including:
- DeepSeek V4 Flash/Pro
- Llama 3.3 70B
- Qwen models
- Gemma 4 31B
- FLUX image models
- Many more

## Getting an API Key

1. Sign up at [together.ai](https://together.ai)
2. Add payment method for pay-as-you-go
3. Export: `export TOGETHER_API_KEY="..."`

## Known Gotchas

- No explicit free tier documented
- Pricing varies significantly by model
- Some models (Ternary Bonsai 27B) are $0.00 (free to use)
- Batch API available for 50% discount
