# NVIDIA Free Tier — Research Summary

**Last verified**: August 2026, via build.nvidia.com.

## What is NVIDIA?

NVIDIA provides LLM inference via their NIM (NVIDIA Inference Microservices) platform.

**Base URL**: `https://integrate.api.nvidia.com/v1`

## Free Tier Limits

| Limit | Value | Notes |
|-------|-------|-------|
| Free credits | $1,000 | One-time on signup (expires after ~30 days) |

## Available Models

Access to NVIDIA-hosted models including:
- Llama models
- Mixtral
- Nemotron
- And more

## Getting an API Key

1. Sign up at [build.nvidia.com](https://build.nvidia.com)
2. Get $1,000 in free credits
3. Export: `export NVIDIA_API_KEY="nvapi-..."`

## Known Gotchas

- $1,000 credits expire after ~30 days
- Free tier is for evaluation/development
- Production use requires paid tier
