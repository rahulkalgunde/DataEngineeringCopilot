# SiliconFlow Free Tier — Research Summary

**Last verified**: August 2026, via siliconflow.cn.

## What is SiliconFlow?

SiliconFlow provides LLM inference for open-source models.

**Base URL**: `https://api.siliconflow.cn/v1`

## Free Tier Limits

| Limit | Value | Notes |
|-------|-------|-------|
| Free credits | ¥14 (~$2) | One-time on signup |

## Available Models

Access to various open-source models.

## Getting an API Key

1. Sign up at [siliconflow.cn](https://siliconflow.cn)
2. Get free credits
3. Export: `export SILICONFLOW_API_KEY="..."`

## Known Gotchas

- Free credits expire after a limited time
- Limited model selection on free tier
- Production use requires paid tier
