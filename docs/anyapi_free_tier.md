# AnyAPI Free Tier — Research Summary

**Last verified**: August 2026.

## What is AnyAPI?

AnyAPI provides a generic interface for various LLM providers.

## Free Tier Limits

| Limit | Value | Notes |
|-------|-------|-------|
| Free credits | Varies | Depends on underlying provider |

## Getting an API Key

1. Sign up at the AnyAPI platform
2. Export: `export ANYAPI_API_KEY="..."`

## Known Gotchas

- Acts as a proxy to other providers
- Free tier depends on the underlying provider's free tier
- Limited documentation available
